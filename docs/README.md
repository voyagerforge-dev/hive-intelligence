## What belongs here, and what does not

This repository documents **the product**. Documentation about applying Hive to a
particular domain belongs in that deployment, not here.

The dividing line is the same one that governs the code: documentation of a **mechanism**
is upstream, documentation of an **application** of that mechanism is downstream. The card
pipeline, the facet model and the retrieval research are mechanisms. Distilling a specific
vendor's product documentation is an application.
